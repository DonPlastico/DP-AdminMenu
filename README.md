1. DETALLES DEL JUGADOR:
- ARREGLAR EL LLENAR COMIDA/BEBIDA
- HACER EL DAR VEHÍCULO SUBIDO
- ARREGLAR LOS BADGES DEL HISTORIAL DE SANCIONES
- EN EL HISTORIAL NO SALEN LOS KICKS
- METER DEBAJO DEL MENÚ DE PED UN BOTÓN INDIVIDUAL "MENÚ TROLL" QUE ABRA UN MODAL CON OPCIONES TROLL (INSPIRARSE EN EL TXADMIN)

2. PAGE ACCIONES:
- ARREGLAR EL ANUNCIOS (NO SE VE EL TEXTO QUE PONGO)
- ARREGLAR EL CONGELAR TIEMPO/HORA DEL MODAL CLIMA
- ARREGLAR EL MODAL DE GESTIONAR PINTURAS

3. PAGE REPORTES:
- REDISEÑAR EL ESTILO, NO ME TERMINA DE CONVENCER
- EN EL INFORMACIÓN DEL JUGADOR (PANEL DETALLES DEL JUGADOR) ESTÁ BUG EL PERFILES ASOCIADOS, EN VEZ DE SALIR NINGUNO, SALEN LOS MIOS CON UN ESTILO RARO Y FEO.
- QUE SE ORDENE DE LOS REPORTES MAS RECIENTES ARRIBA, LOS REPORTES MAS VIEJOS ABAJO

4. PAGE BANEOS:
- CAMBIAR ESTILO Y HACERLO COMO EL DE REGISTRO DE ACTIVIDAD (LOGS) DEL PAGE STATUS
- ARREGLAR EL MODAL DEL GESTIONAR DURACIÓN DEL BANEO (NO VA EL OPTIONS DEL "DÍAS")

5. PAGE CHAT ADMINISTRADORES:
- MODIFICAR EL DIV DE LOS MENSAJES
- ARREGLAR LOS BORDES DEL IMPUT DE ENVIAR MENSAJES

6. PAGE JOBS:
- REDISEÑAR POR COMPLETO

7. PAGE GANGS:
- UTILIZAR EL MISMO REDISEÑO DEL JOBS
- ARREGLAR LOS TOOLTIPS DE LOS BOTONES

8. PAGE DE VEHÍCULOS:
- CAMBIAR ESTILO CSS UNICAMENTE (CAMBIAR COLORES/FORMAS/SOMBRAS Y POCO MAS)

9. PAGE ITEMS:
- UTILIZAR EL MISMO DISEÑO DEL VEHICULOS

10. PAGE STATUS:
- ARREGLAR EL TAMAÑO DE LOS NUMEROS/TEXOS DE LOS BOTONES SUPERIORES
- ARREGLAR LAS GRAFICAS DE FLUJO DE JUGADORES/ACTIVIDAD DE ADMINISTRADORES/REPORTES
- AÑADIR QUE TODO TENGA REGISTRO DE ACTIVIDAD (LOGS)

11. CAMBIAR COMANDOS

12. CSS DEL FOOTER DEL MENÚ, REDISEÑAR LA MAYORIA DE MODALS.

13. COMPROBAR TODO EL SCRIPT ENTERO PARA EVITAR QUE ALGO SE HAYA ROTO
